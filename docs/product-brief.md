# Product Brief

## Working Name

Mnemor Brew Engine

## One-Line Product Definition

An always-ready espresso assistant that captures each shot automatically and recommends the next controlled adjustment for a specific machine, grinder, bean, and user preference.

## Target User

The first target user is not the general coffee drinker.

The first target user is:

- owns premium home espresso equipment
- changes beans often enough to feel dial-in pain
- already understands dose, yield, time, grind, and taste
- is willing to add one small device near the machine
- dislikes active phone/tablet interaction while pulling shots

## Starting Setup

The first reference setup is:

- La Marzocco Linea Micra or comparable high-end home espresso machine
- Acaia Lunar 2021 / AL008 scale
- Niche Zero grinder
- 18 g basket workflow
- local ESP32-based capture device

This narrow start is deliberate. The goal is to prove value in one coherent premium setup before expanding support.

## Core Job To Be Done

When I dial in a bean or return to a previous recipe, I want the system to tell me the next best adjustment so that I waste fewer shots and return to good espresso faster.

## What This Is Not

This is not:

- a generic shot log
- a prettier flow display
- a scale replacement
- an LLM-first coffee chatbot
- a universal Bluetooth device layer
- a La Marzocco or Acaia partnership project at launch

## Product Promise

The product earns its place only if it can say something like:

- "Repeat this shot unchanged."
- "Go slightly finer, keep dose and yield constant."
- "Increase yield by 1 g before changing grind."
- "This bean is drifting faster than previous beans."
- "The last change improved time but worsened flow stability."

## Commercial Hypothesis

Premium home espresso users may pay 149-199 EUR for a dedicated local device if it reliably reduces dial-in attempts and removes phone friction.

This is unproven and must be validated before productization.
