# Go/No-Go Criteria

## Technical Go

Continue if:

- Lunar connection succeeds automatically in at least 95% of sessions.
- Weight stream has no relevant gaps during normal shots.
- Shot start and end detection are at least 95% correct.
- User interaction is below 5 seconds per shot.
- The same input produces the same recommendation.
- At least 50 controlled shots are captured in structured form.

## Product Go

Continue if, among external testers:

- at least 60% use the system after 4 weeks
- at least 50% report fewer dial-in attempts
- at least 40% would pay 149 EUR or more
- users describe the product as useful, not merely interesting
- users follow recommendations without needing long explanations

## Business Go

Continue toward productization if:

- price target of 149-199 EUR seems plausible
- support burden appears manageable
- device works without cloud dependency
- direct-to-community distribution seems realistic
- no strategic partnership is required for first sales

## No-Go

Stop or pivot if:

- recommendations are not better than simple espresso rules
- users do not enter taste feedback
- phone friction is not a meaningful pain
- BLE reliability dominates the experience
- users value the product below 50 EUR
- the product is only useful for beginners
- hardware turns into the main work before user value is proven

## Decision Rule

If M1 and M2 pass but M3 fails, keep the project as a technical tool or open-source logger.

If M3 passes but M4 fails, keep it as a personal premium workflow tool and do not productize.

If M1-M4 pass, start product design and small-batch hardware planning.
